# Conventions

- **Content-as-data**: most sections hardcode their content as a local array of objects at the top of the file (e.g. `Colecao.tsx` obras, `Conexoes.tsx` depoimentos). Exceptions with shared data files: séries live in `src/data/series.ts` (`Serie[]`, `slug` via local `slugify`), entregas live in `src/data/entregas.ts` — edit those files directly rather than the consuming components. Any other content: edit the local array in the component itself, there is no CMS.
- **No shared state/store** between page-level components (`Index`, `SeriePage`, `EntregaPage`) and `Header`/`Footer` — no prop drilling. Each component owns its own local `useState` (e.g. `Header`'s mobile-menu / SERIES-dropdown state).
- **Modal/dropdown open-close pattern**: boolean/nullable state in the owning component; `Escape` + click-outside closes; fade via a `visible` state flipped on mount + `setTimeout` before unmount (see `SlideshowModal` in `Colecao.tsx`, and the lighter non-modal version in `Header`'s SERIES dropdown using the `fadeSlideIn` keyframe in `src/index.css`).
- **Styling**: section background colors frequently set via inline `style={{ backgroundColor: '#...' }}` rather than Tailwind classes — match this in existing sections, don't convert to arbitrary-value Tailwind classes.
- **Images/media**: static assets in `public/`, referenced by root-relative path (`/BG.png`). Filenames are inconsistent/legacy (`IMAGE 11.jpg`, `sci1.jpg`) — check `public/` before assuming a naming pattern.
- **External domains**: any new external image/script/iframe/fetch domain must be added to the CSP in `vercel.json` (script-src/frame-src/img-src/connect-src) or it's silently blocked in prod. Existing allowances: Spotify iframe embed, Google Fonts, picsum.photos (CircularGallery placeholders).
- **Dormant, not dead**: `CircularGallery.tsx`, `TiltedCard.tsx`, `ArtistaCard.tsx` are unimported building blocks; `Carrosel.tsx` is imported in `index.tsx` but commented out. Don't delete without checking with the user first.
